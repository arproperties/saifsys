## 🎯 How It Works

### **Calendar View:**

**1. Navigate Calendar:**
- Use Previous/Next buttons to move between months
- Click "Today" to jump to current month
- Use month/year dropdowns for quick navigation

**2. View Tasks:**
- Tasks appear on their due dates
- Color indicates priority/status
- Number shows task count for the day
- Click any task to see details

**3. Filter Tasks:**
- Select building to see only that building's tasks
- Select asset type to see only that type
- Select status to see only that status
- Filters work together

**4. Task Details:**
- Click any task badge
- Modal shows full task information
- Link to full task management page

---

### **History Page:**

**1. View Statistics:**
- See overview metrics at top
- Total completed, cost, duration, etc.
- Quick insights into maintenance activity

**2. Filter History:**
- Set date range (default: current month)
- Filter by asset, schedule, or building
- See filtered results

**3. View Details:**
- Click "Details" on any record
- See complete maintenance record:
  - What was done
  - Who did it
  - How long it took
  - What it cost
  - Issues found
  - Parts replaced
  - Condition before/after

**4. Analyze Trends:**
- Compare costs over time
- Track maintenance frequency
- Identify recurring issues
- Plan future maintenance
