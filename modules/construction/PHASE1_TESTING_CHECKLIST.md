# Construction Module — Phase 1 Testing Checklist

**Recommendation:** Test Phase 1 before proceeding to Phase 2. Stabilize the MVP before adding new features.

## Quick Test Flow

### 1. Projects
- [ ] Add a project (OWNER type)
- [ ] Add a project (CLIENT type) with a client
- [ ] View project details
- [ ] Edit project
- [ ] Filter projects by status (All, Active, Completed)

### 2. Contractors
- [ ] Add a contractor
- [ ] View contractor
- [ ] Link contractor to project (Project–Contractor)

### 3. Clients (for CLIENT projects)
- [ ] Add a client
- [ ] Edit client

### 4. Contractor Payments
- [ ] Add contractor payment (retention should calculate)

### 5. Project Costs
- [ ] Add project cost (materials, labor, equipment, etc.)
- [ ] View project costs list

### 6. Labor Assignments
- [ ] Assign employee to project
- [ ] View labor list

### 7. Material Issues
- [ ] Record material issue to project

### 8. Client Invoices (CLIENT projects only)
- [ ] Create client invoice
- [ ] Record client payment

### 9. Reports
- [ ] Project Cost Summary
- [ ] Budget vs Actual
- [ ] Contractor Summary

### 10. Navigation
- [ ] Collapsible sections work (Core Management, Partners, Financial, Reports)
- [ ] Switch Module button takes you to select-module

## After Testing

If everything works and the flow is stable → **Proceed to Phase 2** (project phasing, variation orders, advanced controls, document management).
